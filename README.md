## Executive Summary (30 seconds)
Grok is reactive. Users lose context on hang-up. Ideas die unshaped. Health data unused. No proactive loop. Competitors (ChatGPT Health) are moving. These four features make Grok persistent, proactive, and value-generating. Ship PiP first (lowest lift). Pilot Clockwork Coach with DoD/VA.

## The Four Features

### 1. Picture-in-Picture (PiP)
**Problem:** Voice mode forces full-screen takeover. Lose the app/document the moment you talk.
**Solution:** Floating, draggable voice window. Conversation stays visible while you work on any screen/monitor.
**Five-step:** Question full-screen requirement → Delete takeover → Simplify to bubble → Accelerate (ship this quarter) → Automate later.
**Value:** Retention lift + Pro conversion. Lower bound $100M/yr at scale.
**Ask:** Ship Q4 2026.

### 2. Good Idea Fairy (with Lightning Round)
**Problem:** 20k+ ideas/yr at USAA overwhelmed 2 humans → burnout. Forms kill participation. No USPTO/secrecy check. No reward. No talent scout.
**Solution:** Voice-capture raw idea → AI shapes one-page pitch (problem/solution/value: revenue/cost/regulatory) → auto-search USPTO + flag Invention Secrecy Act (35 USC §181) → stage-gate pipeline with community voting → Lightning Round (3-min timed pitch, live screen share, prototype demo, live comments, metrics bar, LOB sponsors) → AI coaches pitch beforehand → public X dial-in weekly → reward + talent scout (co-dev invites, hire pipeline).
**Five-step:** Question form requirement → Delete bureaucracy → Simplify to voice + AI shape → Accelerate cycle (AI canvases millions) → Automate pipeline.
**Value:** Avoided failed projects + faster shipping $50-200M/yr enterprise. IP protection. Talent acquisition.
**Ask:** Consumer voice-capture + USPTO check first. Enterprise pilot with one org's idea pipeline. 5x ROI in 18 months.
**Proof:** US11526165B1 (remote vehicle control, commercial focus, dial-in co-pilot). USAA mobile deposit originated from similar crowd idea culture.

### 3. Clone Me
**Problem:** Digital avatars fail — not enough data to sound like the real person.
**Solution:** Opt-in continuous capture (voice, conversations, decisions) over months → persistent behavioral model. Family/trustees talk to the real you. Legal-entity link in AI-citizen jurisdictions (UAE). Delete generic avatars.
**Five-step:** Question generic avatar → Delete low-data versions → Simplify to opt-in capture → Accelerate training → Automate legal/consent.
**Value:** Retention + paid conversion. Afterlife/family use. Trust administration. Lower bound $100M/yr.
**Ask:** Consent toggle + 12-month capture pilot.

### 4. Clockwork Coach
**Problem:** MHS spends $64B/yr (FY2026, 9.4M beneficiaries). Veteran suicides 6,398 in 2023; 61% had zero VA contact in final year. ChatGPT Health connects Apple Health + Epic. DoD buying WHOOP/Oura. Grok has none. Reactive chat loses user on hang-up.
**Solution:** Proactive daily calls/texts at set times. Biometric-driven plan (Whoop/Oura/Apple Health). Fasted PT window. Streaks. Projected healthy years. Enterprise: unit readiness dashboards, fatigue risk, suicide-risk flagging via conversation + biometrics.
**Five-step:** Question reactive requirement → Delete manual tracking → Simplify to proactive voice + biometrics → Accelerate daily loop → Automate risk flagging.
**Value (conservative, 5-10x filter):**
- 1% MHS efficiency = $640M/yr.
- 1% suicide reduction (~64 lives) at HHS VSL $13.6M = $870M/yr.
- Combined $1.5B/yr at 1%.
- NFL injury spend $540M/yr; 10% cut = $54M/yr.
**Ask:** Consumer Clockwork Coach (Apple Health + Whoop). Enterprise pilot with one DoD unit or VA cohort. 5x ROI in 18 months on suicide + MHS lines.
